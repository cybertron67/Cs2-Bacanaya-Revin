# Electricity Bill Calculator

# Description

  This program calculates your electricity bill with just simple inputs!

# Version 1

  Input - Asks for your name, past input reading and current input reading.
  Process - Calculates and displays the electricity bill
  Output - Customers name, your electricity consumption, and your total bill in PHP
  Input validations: 
    1. Customer name -- Must not be empty
    2. Previous reading -- Number at least 0
    3. Current reading -- Number at least the previous reading
